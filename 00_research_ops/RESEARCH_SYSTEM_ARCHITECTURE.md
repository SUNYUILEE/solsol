# V3 연구 운영체계 → 연구기록 → 설명문서 → 승격

```text
사용자 원문
   ↓
00_research_ops  (행동 권위·게이트)
   ↓
01_목표 ~ 12_협업  (과학 연구의 중앙 기록)
   ↓
승인 대상?
 ├─ 아니오 → 기존 연구기록/실행/artifact에 계속 보존
 └─ 예     → Git promotion checkpoint → APPROVED/CANONICAL/RELEASED
   ↓
13_설명문서
근거 인덱스 → 장별 근거패킷 → 상세 원고 → 시각화 → Word → 문서 QA → 독립 검토
   ↓
설명문서 승인 시 Git promotion checkpoint
```

`00_research_ops`가 행동 권위이고 `01_목표~12_협업`이 연구 원장이다.  
`13_설명문서`는 원장을 변경하지 않는 **읽기 기반 출판 계층**이다.

구조 PASS, Git PASS, 문서 PASS는 과학·실험·현장성능 PASS가 아니다.
