SOLSOL 계산기 사용과 검산

계산기로 돌아가기

평가점을 촘촘하게 바꾸면 결과도 달라지나요?

저장 실행과 지도 배치를 선택하고 해품질·검산 → 검산·개선 배치 → 평가점을 더 촘촘히 잡아도 성능이 유지되나요?를 엽니다. 간격을 선택하고 시작 버튼을 누르면 같은 센서 위치·수량·후보·비용으로 두 번 평가합니다. 새로운 위치 탐색은 하지 않습니다.

표의 변화는 평가점 간격에 따른 성능 차이입니다. 차이가 작으면 시험한 두 간격에서 안정적이라는 근거입니다. 참값 오차나 최적일 확률은 아닙니다. 영역 커버율과 모델의 품질 목적값은 별도로 읽으세요. 목표를 설정하지 않았다면 합격·불합격을 만들지 않습니다.

RF와 HMSP-2D에서 지원합니다. EOIR은 공개 모델의 격자 입력 계약 보완이 필요하여 사유를 표시합니다. 저장된 간격 비교로 이전 결과를 다시 읽고 근거를 내려받습니다. 원래 최적화 해집합은 바뀌지 않습니다.

100개만 보면 다른 대안을 놓치지 않나요?

다른 관측 배치 비교 → 추려 본 배치가 놓치는 것은?을 펼치세요. 좁은 화면은 왼쪽 해집합 분석으로 들어갑니다. 같은 실행·세대·목표·영역 조건에서 추출 전 전체와 대표 집합을 비교합니다.

성능 손실이 작을수록 전체 관측 성능을 잘 대신합니다. 0이어도 다른 설치 위치를 모두 담았다는 뜻은 아닙니다. 그래서 가까운 대표까지 위치 차이를 따로 표시합니다. 동일 종류 센서 한 대를 옮기면 보통 2비트 차이입니다. 손실은 정규화 거리이며 신뢰 확률이나 커버율 %가 아닙니다.

생략된 대안을 확인하려면 추출 전 전체 배치 보기를 누르세요. 목표와 영역 필터는 유지됩니다. 계산 기준을 펼치면 최대 손실의 실제 두 배치 번호와 목적값을 읽고, 같은 실행의 근거를 내려받을 수 있습니다.

질문을 고르고 실제 근거 확인하기

저장 실행을 선택하고 해품질·검산 → 해집합 판단을 엽니다. 조건을 지킨 관측 배치, 최종 비지배 배치, 목표 통과 부분집합을 먼저 확인합니다. 목표 미설정은 0개 합격이 아니라 판정 안 함입니다.

  1. 얻은 해집합: 어떤 대안을 확보했는지 읽고 성능·목표 비교를 엽니다.
  2. 탐색의 진전: 초기 → 전체 관측 최선을 목적별로 비교합니다. 목적마다 최선 배치가 다를 수 있습니다. 곡선의 마지막 100%는 자기 최종집합 기준이며 최적일 확률이나 지도 면적이 아닙니다.
  3. 반복 결과: 일부 배치를 개선한 반복과 전체 배치를 개선한 반복을 구분합니다.
  4. 위치 변경 검산: 저장 검산이 있으면 해당 결과·개선 지도를 바로 엽니다. 없으면 범위를 선택하는 준비 화면으로 갑니다. 준비 화면의 시작 버튼을 눌러야 새 검산이 실행됩니다. 검산 예산 제한은 없고 중지·재개할 수 있습니다.
  5. 수치 재현: 같은 모델에서 재현된 값과 독립 검증을 구분합니다. 자세한 방법과 출처를 펼쳐 볼 수 있습니다.

예시: 원해 두 개에서 같은 개선 배치를 찾았다면 발견 평가행은 2개, 서로 다른 개선 배치는 1개입니다. 이 판단과 실행 근거 내려받기는 현재 실행과 판단을 함께 저장합니다.

두 배치를 지도에서 비교하기

왼쪽 배치 비교는 기준 A와 대안 B를 나란히 보는 화면입니다. 해집합 분석의 체크칸은 여러 배치의 표를 좁혀 보는 필터이며 지도 비교 메뉴가 아닙니다.

  1. 저장 실행을 선택하고 배치 비교를 누릅니다. 지도 탐색에서 마음에 드는 배치를 찾았다면 이 배치를 기준 A로 비교를 누르세요.
  2. 기준 A · 왼쪽에서 비교 기준을 선택합니다. A는 오른쪽 배치나 페이지를 바꿔도 유지됩니다.
  3. 대안 B · 오른쪽에서 배치를 선택하거나 이전 B / 다음 B를 누릅니다. 위에서 아래로 지도, A에서 B로 바꾸면 수치표 순서로 읽으세요.
  4. 표의 개선/저하는 각 목적의 최대화·최소화 방향을 반영합니다. % 지표의 차이는 %p입니다. 비용이 같으면 같은 비용에서 성능과 위치를 비교합니다. Hamming은 설치 차이이지 성능 순위가 아닙니다.
  5. 최종 해 이외의 배치가 필요하면 비교 대상 목록·필터를 엽니다. 최종 해, 세대별 이력, 관측 배치를 구분하고 목록에서 대안 B를 고릅니다. 지도 비교로 돌아가기를 누르면 두 지도와 수치 차이가 보입니다.
  6. 공통 레이어를 바꾸거나 확대 비교를 열어 같은 A/B를 확인합니다. 영역 커버율·저장 목표·출처에는 실행·세대·원시 배치 번호가 있습니다.

절충 비교는 최종 해집합 전체의 성능 간 관계를 그래프로 읽는 별도 분석입니다. 위 두 지도 비교는 내가 고른 특정 두 배치의 위치와 값 차이를 확인합니다. 품질·검산은 원시 재평가·탐색 변화·추가 검사와 개선 배치의 근거를 확인합니다.

실행 방법

바탕화면 SOLSOL 계산기를 더블클릭합니다. Codex가 없어도 모델 서비스와 계산기가 자동으로 시작됩니다. 이미 열린 서버는 재사용합니다. 브라우저 창을 닫아도 계산 중인 서버는 계속 동작합니다.

대체 실행: 프로젝트 폴더의 START_INTEGRATED_UI.cmd. 시작 오류는 안내 창과 07_실행/integrated_service 로그에 남습니다. Python과 solsol, solsol_Model 폴더가 필요합니다.

계산을 마친 뒤 이렇게 판단하세요

  1. 저장 실행의 품질·근거를 여세요. 맨 위 결론과 센서 수량·목표 설정이 실행한 조건인지 확인합니다.
  2. 계산 결과와 탐색 성과에서 조건 통과 배치 수, 최종 성능 범위를 읽습니다. 계산 재현 PASS는 성능이 최고라는 뜻이 아닙니다.
  3. 같은 계산량으로 다시 탐색했을 때에서 실제 개선 사례를 골라 지도 두 개와 성능 변화표를 비교합니다. 목적별 최대값을 합친 가상 배치를 보여주는 것이 아닙니다.
  4. 최종 해집합 검산·개선 배치 보기를 누릅니다. 기본값은 최종 비지배 해 전체를 대상으로 센서 위치 등을 한 번씩 바꾸는 검사입니다. 저장 검산이 있으면 개선 지도부터 볼 수 있습니다. 새로운 검산은 범위를 선택하고 실행하며, 중지/이어서 검사가 가능합니다.

원래 탐색, 난수를 바꾼 반복 탐색, 사후 검산에서 찾은 개선은 각각 출처가 다릅니다. 전량 사용 조건을 위반하는 삭제 결과는 유효한 개선해가 아닙니다. 한 번의 이동 검사와 전체 설치 조합 검사는 확인한 공간이 다릅니다.

현재 예산에서 얻은 해집합을 어떻게 신뢰하나요?

품질·근거의 개선 곡선은 평가 횟수를 늘리는 동안 확보한 성능 공간이 얼마나 증가했는지 보여줍니다. 100%는 관측한 비교 기준이며 최적일 확률이나 지도 커버율이 아닙니다. 마지막 구간의 이득은 이미 사용한 예산에서 측정한 값입니다.

같은 조건·평가 횟수에서 난수만 바꿔 반복하면 결과 변동을 볼 수 있습니다. 반복별 성능 범위와 비교 기준 성능을 달성한 횟수를 함께 읽으세요. 관측 변동이 작다는 근거와 위치 이동으로 개선해를 찾았다는 근거는 동시에 성립할 수 있습니다. 전자는 반복성을, 후자는 개선 가능성을 설명합니다.

계산 방법 펼치기에는 HV(같은 기준점까지 확보한 성능 공간), IGD+(관측 비교 기준에 대한 평균 부족 거리), 고정 척도와 논문 링크가 있습니다. 실제 성능값·수량·제약·위치 다양성은 별도로 유지합니다. 목표를 끄면 성능 비교는 계속하되 합격 확률을 만들지 않습니다.

공통 설정과 모델 차이

공통 계산기모델 계약에 따른 차이
영역·후보지·평가점·기간, 초기 배치·알고리즘·예산, 저장·지도·비교센서 파라미터, 목적·비용·제약 평가, 관측 불가능 상태
Radar+EO/IR, Radar+RF, HMSP-2D는 공통 지도 설정명시 입력 HMSP는 외부 품질·비용과 명시 좌표가 필요하고 선언된 영역 경계가 없음
전체 Model 허용 후보에서 선택하며, 보유 수량과 정량 목표를 별도 처리목표를 끄면 성능 기준 필터가 없어지는 것이며 설치 영역·수량 제한은 유지

모델을 바꾼 뒤 확정 설정, 후보 수·반경/영역 비율과 좌우 미리보기를 확인합니다. 과거 저장 결과는 당시 조건으로 읽으며 새 초안과 섞지 않습니다.

현재 계산 결과는 왜 좋거나 부족한가요?

품질·근거 탭에서 저장 조건, 선택 배치의 제약, 초기 및 전체 관측 최선, 반복 평가와 위치 다양성을 확인합니다. 목표 OFF는 성능 합격 기준 미설정이며, 원시 재생 PASS는 수치 재현 확인입니다. 검산 개선 후보가 발견되면 원해보다 개선 여지가 있다는 뜻입니다. 미완료나 오류는 개선 없음으로 판정하지 않습니다.

검산 결과·지도 열기로 원래 값, 개선 값, 좋아진 양과 설치 지도를 비교합니다. 센서 중심이 평가영역 밖이어도 설치 허용 조건을 만족하면 유효하며 평가영역 커버 성능으로 비교합니다.

해품질·탐색 품질·검산은 어디에 있나요?

저장 실행을 선택하고 상단 해품질·검산을 누릅니다. 모델 1 Radar+EO/IR, 모델 2 Radar+RF, 모델 3 HMSP-2D는 같은 공통 검사 목록을 사용합니다.

  1. 세대별 NFE·고유 배치·중복 평가·비지배 해 수와 초기화 근거를 확인합니다.
  2. 선택 배치 / 전체 비지배 / 저장 목표 통과 전체 중 검사 대상을 정합니다.
  3. 전체 삭제·추가·위치 이동, 전체 이웃 MILP·ε-constraint, 전체 설치 조합 중 검사 범위를 선택합니다.
  4. 검산 평가 횟수·시간 예산은 없습니다. 선택한 범위를 완료할 때까지 서버에서 실행합니다. 화면의100개 페이지와 내부 평가 묶음은 계산 제한이 아닙니다.
  5. 검산 중지 버튼으로 중지하고 저장 지점부터 계속할 수 있습니다. 서버가 꺼졌다면 중단됨으로 표시합니다. 코드나 원시 조건이 바뀌면 과거 지점을 조용히 이어가지 않습니다.
  6. 개선 배치를 원래 배치와 지도·F·비용으로 비교하고 전체 근거 ZIP을 내려받습니다. 개선 후보는 원시 archive에 끼워 넣지 않습니다.

중지 요청은 현재 Model 또는 MILP 응답 이후 처리합니다. 전량 사용에서 삭제·추가는 재고 위반이므로 개선 후보에 포함되지 않을 수 있습니다.

MILP·ε-constraint·전체 조합 검산의 의미

전체 이웃 MILP는 선택 배치의 모든 단일 삭제·추가·위치 이동을 원래 Model로 평가한 뒤, 다른 목적의 F가 원래 해보다 나빠지지 않는 조건(ε 상한)에서 각 목적의 최솟값을 구합니다. MILP 결과를 후보의 직접 최소값과 대조합니다. 이는 검사한 전체 이웃의 판정이며 전체 비선형 설치 공간의 전역 MILP 증명은 아닙니다.

전체 설치 조합은 선언된 설치 영역·후보·정확/최대 재고·공동 설치 조건의 모든 조합을 열거하고 Model F/G와 저장 목표로 검산합니다. 9비트·512평가 제한은 없습니다. 조합 수가 큰 실제 문제는 매우 오래 걸릴 수 있습니다. 진행 중 조합 상한과 평가 수를 표시하며, 끝까지 완료한 경우에만 그 고정 이산 공간의 판정으로 해석합니다. 중지·오류를 완료로 표현하지 않습니다.

초기 배치 생성의 국소근사 MILP와 사후 검산의 MILP는 별개입니다. 정량 목표는 저장 실행의 값이며, ε 비교 상한은 원래 해의 최적화 F입니다. HV/IGD+는 고정 reference·정규화 조건이 필요합니다. 반복 연구는 계산 탭의 선택형 Validation Run 구성·복원에서 확인합니다.
