# 전체 이식 교정 기록

사용자가 지적한 0.1 축소 대체 구현을 전체 계산기 보존으로 오인한 완료 주장을 철회하고 범위를 다시 설정했습니다. 현재는 원본 공통 엔진·전체 workspace·품질 기준·공개 client/API와 상세 연구 서비스를 사용합니다. 이전 제출의 결과·검증 PASS를 현재 범위에 상속하지 않습니다.

실제 검증에서 발견한 교정은 다음과 같습니다.

- 중립 모델 ID를 막던 공통 자원·반경·격자·예산 연구의 기존 모델 가드를 연결 계약으로 수정했습니다.
- 재고 검산의 uint8 빼기 underflow와 checkpoint/BinaryDecision의 JSON 직렬화 문제를 새 복사본에서 고쳤습니다.
- 공통 자원 정규화 뒤 수량 입력이 나타나지 않던 포커스 보호를 구조 변화에 대응하게 고쳤습니다.
- 원본 화면의 센서 요약·지도·명시 경계·단위·좌표 눈금·축척을 중립 모델과 연결했습니다.
- 공개 CLI의 별도 저장소, 취소 body, OpenAPI 경로, 모델별 defaults와 일반 compiled-builder 등록을 수정했습니다.
- 폼→계산→저장·재시작 복원·모델 전환을 실제 Edge로 확인했습니다. 자동화의 잘못된 selector/대기 조건은 제품 실패와 구분해 교정했습니다.
- 하네스에 파일·컨트롤·증거 누락, 허위 모델 제외, 존재하지 않는 대체 함수, 잘못된 proof domain에 대한 차단 검사를 추가했습니다.
- 참고 파일 보존은 `PRESERVED_NOT_EXECUTED`로 표시하고 실행 검증 PASS와 구분했습니다.
- 깨끗한 임시 소스와 새 가상환경에서 선언된 의존성만으로 설치·HTTP 실행을 확인했습니다. 기존 ignored build cache의 Windows 권한 문제는 원본/캐시 삭제 없이 격리 빌드로 해결했습니다.
- 운영 하네스는 새 중립 프로젝트의 빈 기록 구조로 초기화하고 doctor/system-audit와 별도 회귀검사를 실행했습니다. 과거 승인·작업·실험 기록은 이식하지 않았습니다.

전체 자동검사·브라우저·독립 검토·파일 해시·원본 보존·패키지·운영 근거는 검증 인덱스에 연결합니다. 현장 성능과 독립 과학 검증은 앞으로 각 모델·실험의 실제 증거로 축적해야 합니다.
