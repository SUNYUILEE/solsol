# 보이는 조작과 설명을 검증하는 운영 보완

Task: TASK-20260909T030353Z-DAD549B6. R06/r06_review. CHANGE_INTEGRATION의 이번 변경 영향 검토 기준. 기존 품질기준을 낮추거나 제품 전체 PASS를 부여하지 않는다.

## 이전 검증의 충분성 오류

직전 검토는 큰 지도·해 선택·군집 지연 교정에 국한되었다. 그 범위의29개 검사가 통과해도 센서 편집 버튼, 상세 분석 진입, 원시 JSON의 사용자 설명, 현재 선택과 무관한 연구 화면은 검증되지 않았다. 사용자가 해당 핵심 과업을 수행하지 못했으므로, 부분범위 PASS를 전체 사용 가능성으로 확대하는 운영상 오류를 인정한다. 기존 결과를 삭제하거나 조용히 범위를 바꿔 정당화하지 않고 새로운 원문 요구와 실패 기록에 연결한다.

내부 함수 호출 또는 page.evaluate로 선택/모드/필터 값을 주입한 검사는 상태 단위검사다. 실제 보이는 조작의 end-to-end 근거로 사용할 수 없다. 비공개 함수 호출로 패널을 연 뒤 DOM이 있다는 주장 역시 버튼이 보이는지·클릭되는지·사용자가 결과를 이해하는지를 입증하지 않는다.

## 이번 must-pass 과업

1. 일반 진입 URL에서 시작해 실제 저장 실행 선택기를 사용하고, 화면에 보이는 해를 클릭한다. 센서 속성 편집 버튼의 위치·가시성·enabled 상태를 확인한 뒤 클릭한다. 설정 패널이 실제 viewport에 열리고 해당 센서 탭/필드에 focus가 간다. 숫자를 실제 입력·조건 반영하고 바뀐 초안과 고정 저장 결과가 구별되는지 확인한다. private state 주입으로 대체하지 않는다.
2. 원시 목적값/고정 조건을 펼쳐 사람이 읽는 표·단위·용어 설명을 확인한다. JSON 문자열을 pre에서 div로 옮기는 것은 교정이 아니다. 필요한 원시 근거는 별도 내보내기로 남기며 사용자 설명과 분리한다.
3. 보이는 상세 분석 버튼을 클릭한다. 같은 workspace의 contract/run/generation/row가 제목과 요청·응답·결과에 유지되어야 한다. 이전 UI로 가거나 기본 실행/새 시나리오로 바뀌면 실패다. 분석을 닫아도 선택·지도·세대가 유지되어야 한다.
4. 실제 선택 배치 검산 버튼을 클릭해 대기/계산중/완료 또는 실패를 관찰한다. 결과에 검사한 행, 원래 목적값·비용, 검사 범위, 개선 증거, 미검사 여부가 표시된다. 이동/제거 증거는 원시 optimizer 해로 편입하지 않는다. 분석 중 다른 해/세대/계약으로 이동했을 때 낡은 응답이 새 선택의 증거로 표시되지 않는지 검사한다.
5. 실제 해집합 분석 버튼을 클릭해 '현재 세대 누적 집합'인지 '저장된 실행 전체'인지 읽고 확인한다. 선택1개의 검산을 전체집합 PASS로 표시하지 않는다. raw 재생·비지배 판정·탐색 중복·Hamming·목표통과·exact/reference·국소 검산이 각자 무엇을 보증하고 못 하는지 설명해야 한다.
6. 과거 고정 RF 연구에 진입한다면 현재 설정/선택 해의 검산과 관계없다는 설명을 진입 전/상단에 둔다. 고정조건·실행일·원본failed·1800초초과·26개 비어있지 않은 배치 미통과/9빈배치의 공허한PASS를 설명한다. 이번 요구에서 과거 연구를 다시 실행하는 버튼은 읽기 전용 안내로 대체하고 원본기록은 보존한다.
7. 위 과업을 EOIR/RF 양쪽과 대표 크기에서 실제 버튼으로 수행한다. pending/disabled/오류/미검사/빈결과와 재조회도 포함한다. 시험은 시작 URL→locator→실제행동→사용자에게 보이는결과→identity/raw핀으로 기록한다. 비공개함수 검사·HTTP만 검사·실제브라우저 검사를 따로 분류한다.

검사 범위는 기능 이름 목록이 아니라 사용자가 끝까지 수행한 과업 단위로 기록한다. 미실행 과업은 NOT_RUN이며 유사 기능 PASS로 상속하지 않는다. 새 source가 이전10개연구핀에 영향을 주면 snapshot·derivation으로보존하고 현재UI개선과역사적연구게이트를혼동하지않는다. R03 구현, R04 자동/실제 과업검사, R06 독립 의미·근거검토를 분리하며 최종 사용자 수용을 대신했다고 주장하지 않는다.
