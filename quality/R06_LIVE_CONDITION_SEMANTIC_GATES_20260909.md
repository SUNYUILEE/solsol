# 조건 편집의 의미 검증 보완

TASK-20260909T050219Z-C4030B71 / R06. 이전63개 검사는 화면 이동·선택·가시성 중심이었다. 동일 NSGA-III에서 서로 다른 checkpoint 용어, 총수량만 있는 RF설정,0.5 목표의 불명확성, m/km 혼용, 숨은 반영 후 화면전환은 그 통과항목으로 검증되지 않았다. 검사가 '보이는 버튼을 눌렀다'에서 멈추고 사용자가 예측한 조건 변화와 실제 계산 계약을 연결하지 못한 운영 간극이다. 이 실패를 과거PASS 삭제나 사용자 표현 완화로 처리하지 않는다.

이번 필수 변경검사:

1. 저장 배치의 왼쪽 조건·지도는 고정하고 오른쪽 초안 입력을 변경하면 입력 focus와작업모드를 유지하면서 새로운 기하가 자동갱신된다. 반영 전후 표시와 실제 preview payload가 일치한다. 불완전 숫자/유효하지 않은 입력은 이전유효지도를새조건인척표시하지않고오류/대기상태를알린다.
2. 빠른 연속 입력A→B 및 센서전환에서 늦은A응답이B초안을덮지 않는다. 자동미리보기는optimizer실행이아니다. 오른쪽미리보기를봐도왼쪽원시run/config/hash는변하지않는다.
3. 반경의표시km/저장m,오차각도°/내부rad,TOAns/환산m,비용점/연도,원면적비/실제커버율을검사한다. 단위통일은물리량을동일하게만드는뜻이아니다.
4. 수량 일부/전부/제한없음과각센서상한을실제X/G/비용내역에대조한다. 상한 Radar2/RF4를total6만검사해서통과시키지않는다. 이전계약은기존G와복원정체성을유지한다.
5. 사용자진화세대g가초기0…g와P(g+1)NFE로이어짐을실제소형실행으로확인한다. 두계약에서서버가지원하지않는선택을실행가능처럼노출하지않는다. 시간상한/평가상한과목표선의관계를설명한다.
6. RF50점은평균정규화품질필터로표시한다. 무관측0점과누적해목표통과집합/원시전체집합을분리한다. 정규화L변경을측정정확도개선으로표현하지않는다. 목표기본값의근거가없으면미설정으로시작한다.
7. 프리셋은'합성 민감도 예시'임을표시하고측정가능한σ변환/수식근거를연결한다. 임의하드웨어권장범위나σ1단계증감만을이론기반UI로포장하지않는다. 자유입력·재열기·사용자수정값보존도확인한다.
